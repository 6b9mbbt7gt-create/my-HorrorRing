# HorrorRing 要件定義書

## 1. プロジェクト概要

### 1.1 サービス名
HorrorRing（ホラリング）

### 1.2 サービス概要
ホラーゲーム、心霊スポット、都市伝説などの情報を集約したSNSプラットフォーム。ユーザーが各ジャンルのコンテンツ（レビュー、体験談、写真、動画）を投稿し、コミュニケーションを取ることができる。

### 1.3 ターゲットユーザー
- ホラーゲーム愛好家
- 心霊スポット探索者
- 都市伝説に興味のある人
- ホラーコンテンツを楽しむコミュニティ

### 1.4 主要機能
- 投稿機能（テキスト、画像、動画）
- コミュニケーション機能（コメント、いいね、ハート、フォロー、DM）
- 検索・フィルタリング機能
- サブスクリプション機能
- 多言語対応（日本語・英語）

---

## 2. 技術スタック

### 2.1 フロントエンド・バックエンド
- **フレームワーク**: Next.js 14+ (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS（推奨）

### 2.2 データベース
- **DB**: Turso (SQLite)
- **ORM**: Drizzle ORM または Prisma（推奨: Drizzle）

### 2.3 認証
- **認証プロバイダー**: betterAuth
- **ログイン方法**: Google OAuth

### 2.4 決済
- **決済プロバイダー**: Polar（開発者向けサブスク決済サービス）
- **サブスクリプション**: 月額課金（Polarのチェックアウト/ポータルを利用）

### 2.5 ストレージ
- **画像・動画保存**: Cloudflare R2
- **CDN**: Cloudflare（R2と統合）
- **バックアップ**: R2の自動レプリケーション機能を活用

### 2.6 その他
- **地図表示**: Google Maps API（心霊スポット用）
- **通知**: サーバーサイド実装 + メール通知（必要に応じて）

---

## 3. 機能要件

### 3.1 認証・ユーザー管理

#### 3.1.1 ログイン
- Googleアカウントでのログイン（betterAuth経由）
- 初回ログイン時にユーザーアカウントを自動作成
- プロフィール情報の編集機能

#### 3.1.2 プロフィール
- ユーザー名、プロフィール画像、自己紹介文
- 投稿履歴、いいね履歴、ブックマーク一覧
- フォロー/フォロワー一覧
- プロフィールカスタマイズ（有料プランのみ）

#### 3.1.3 年齢制限
- サービス冒頭で18歳以上であることを確認する警告表示
- 同意しない場合はアクセス不可

---

### 3.2 投稿機能

#### 3.2.1 投稿タイプ
- **レビュー**: ホラーゲーム、心霊スポット、都市伝説のレビュー
- **体験談**: 実際の体験や訪問記録
- **写真**: 心霊スポットや関連画像
- **動画**: 体験動画やゲームプレイ動画

#### 3.2.2 投稿コンテンツ
- **テキスト**: マークダウン対応（推奨）
- **画像**: JPEG, PNG, GIF, WebP, AVIF
  - 無料プラン: 1投稿5枚まで、1枚5MBまで
  - 有料プラン: 無制限、1枚20MBまで
- **動画**: MP4, WebM, MOV
  - 無料プラン: 不可
  - 有料プラン: 無制限、5分/500MBまで

#### 3.2.3 投稿制限
- **無料プラン**: 1日5投稿まで
- **有料プラン**: 無制限

#### 3.2.4 投稿の公開範囲
- 公開（全ユーザーに表示）
- 非公開（自分のみ）
- 友達のみ（フォロー中のユーザーのみ）
- 限定公開（特定のユーザーグループ）

#### 3.2.5 ジャンル分類
- **ホラーゲーム**
  - プラットフォーム: PC、コンソール、モバイル
  - 発売年、評価、レビュー項目（恐怖度、おすすめ度）
- **心霊スポット**
  - 位置情報（正確な座標、Google Maps連携）
  - 地域、種類（廃墟、病院、学校など）
  - 地図表示は任意（心霊スポットを選択したときのみ表示可能）
- **都市伝説**
  - 地域別、カテゴリ別の分類

---

### 3.3 コミュニケーション機能

#### 3.3.1 コメント機能
- 投稿へのコメント投稿（必須機能）
- コメントへの返信（スレッド形式）
- コメントの編集・削除

#### 3.3.2 いいね機能
- 投稿へのいいね（必須機能）
- 無料プラン: 1日制限あり（具体的な数は要検討）
- 有料プラン: 無制限
- いいね一覧の表示

#### 3.3.3 ハート機能
- 投稿へのハート送信（Yahoo知恵袋のようなイメージ）
- ハート数が多いほど人気記事として上位表示
- 無料プラン: 1日3個まで
- 有料プラン: 無制限
- 1投稿に1回のみ送信可能

#### 3.3.4 フォロー機能
- ユーザーのフォロー/フォロワー機能（必須機能）
- フォロー中のユーザーの新規投稿をタイムラインに表示

#### 3.3.5 DM（ダイレクトメッセージ）機能
- ユーザー間のプライベートメッセージ（必須機能）
- 無料プラン: 1日5通まで
- 有料プラン: 無制限
- メッセージの既読/未読表示

#### 3.3.6 ブックマーク機能
- 投稿のブックマーク保存（有料プランのみ）
- ブックマーク一覧の表示・管理

---

### 3.4 検索・フィルタリング機能

#### 3.4.1 検索対象
- 投稿
- ユーザー
- 心霊スポット
- ゲーム
- 都市伝説

#### 3.4.2 フィルタリング
- **無料プラン**: 基本検索のみ
- **有料プラン**: 
  - 高度なフィルタリング（ジャンル、地域、評価、日付、人気順）
  - 保存検索機能

---

### 3.5 サブスクリプション機能

#### 3.5.1 プラン構成
- **無料プラン（梅）**
  - 月額: 0円
  - 広告表示: あり
- **有料プラン（松）**
  - 月額: 1,000円
  - 広告表示: なし

#### 3.5.2 特典比較表

| 特典項目 | 無料プラン（梅） | 有料プラン（松） |
|---------|----------------|----------------|
| **投稿数制限** | 1日5投稿まで | 無制限 |
| **いいね回数** | 1日制限あり | 無制限 |
| **ハート送信数** | 1日3個まで | 無制限 |
| **画像アップロード** | 1投稿5枚まで、1枚5MBまで | 無制限、1枚20MBまで |
| **動画アップロード** | 不可 | 無制限、5分/500MBまで |
| **広告表示** | あり | なし |
| **限定コンテンツ** | なし | 全てアクセス可能 |
| **プロフィールバッジ** | なし | あり（松バッジ・特別デザイン） |
| **DM送信数** | 1日5通まで | 無制限 |
| **検索機能** | 基本検索のみ | 高度なフィルタリング + 保存検索 |
| **プロフィールカスタマイズ** | 基本のみ | カスタムテーマ + アニメーション |
| **ブックマーク機能** | なし | あり |

#### 3.5.3 決済フロー
- Polar経由でのサブスクリプション登録
- クレジットカード決済（Polarが提供する決済手段を利用）
- 自動更新（月額）
- 解約機能（Polarのカスタマーポータル／管理画面から実施）

---

### 3.6 通知機能

以下のイベントで通知を送信：
- フォローされた時
- 投稿にコメントがついた時
- 投稿にいいね/ハートがついた時
- DMが届いた時
- フォロー中のユーザーが新規投稿した時
- サブスクリプション更新のリマインダー

---

### 3.7 多言語対応

#### 3.7.1 対応言語
- 日本語（デフォルト）
- 英語

#### 3.7.2 実装方法
- デフォルト言語: 日本語
- ユーザー設定で言語切り替え可能
- コンテンツの翻訳: ユーザー投稿（自動翻訳は今後の検討事項）

## 4. 非機能要件

### 4.1 パフォーマンス
- ページ読み込み時間: 3秒以内
- 画像・動画の最適化（圧縮、遅延読み込み）
- CDN経由での配信

### 4.2 セキュリティ
- HTTPS必須
- 入力値のバリデーション（サーバーサイド）
- XSS対策
- CSRF対策
- レートリミット実装

### 4.3 可用性
- サーバーダウンタイム: 月99.9%以上
- バックアップ: 日次自動バックアップ

### 4.4 スケーラビリティ
- ユーザー数増加に対応できる設計
- データベースのパーティショニング検討

## 5. データベース設計（概要）

### 5.1 主要テーブル（想定）

- `users` - ユーザー情報
- `posts` - 投稿
- `comments` - コメント
- `likes` - いいね
- `hearts` - ハート
- `follows` - フォロー関係
- `messages` - DM
- `bookmarks` - ブックマーク（有料プランのみ）
- `subscriptions` - サブスクリプション情報
- `notifications` - 通知
- `haunted_spots` - 心霊スポット情報
- `games` - ゲーム情報
- `urban_legends` - 都市伝説情報

### 5.2 ストレージ
- 画像・動画はS3/R2に保存
- メタデータのみDBに保存
